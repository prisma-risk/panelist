# Changelog

All notable changes to Panelist will be documented in this file.

## 0.2.0 - 2026-08-17

- Add datasource variables and complete persisted state for query and custom variables.
- Add typed value mappings, threshold overrides, and common stat, time-series, gauge, and bar-gauge options.
- Add configurable dashboard revision and cursor synchronization metadata.
- Add typed Grafana query-editor selection and Grafana 11 provisioning coverage.

## 0.1.0 - 2026-08-16

- Initial public release.
- Add typed dashboard, panel, query, variable, field, and datasource builders.
- Add `dashboard!`, `promql!`, and `loki!` macros.
- Add deterministic Grafana JSON serialization and validation.
