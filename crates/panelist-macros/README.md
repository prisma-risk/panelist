# panelist-macros

Procedural macros for [Panelist](https://crates.io/crates/panelist), a Rust library for writing Grafana dashboards as concise, strongly typed code.

This crate is an implementation detail. Depend on `panelist` and use `panelist::dashboard!` or `panelist::prelude::*`; the two crates are released together at the same version.
